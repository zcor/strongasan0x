{% comment %} Shared expand/collapse behavior for .elist-item rows (wins editor, habits editor, archived panel). Mark the list container with data-elist-accordion: the chevron (.elist-toggle) toggles its row, tapping a collapsed heading expands it, and expanding one row collapses its siblings. State is the collapsed/expanded class pair on the item; each editor's CSS decides what those classes reveal (details only, or the label <-> rename-input swap). Delegation is document-level on purpose: the archived dialog injects its panel via innerHTML, where per-element listeners (and inline scripts) never attach. window.elistSetExpanded(item, expanded) is the programmatic hook; an optional item.__onElistExpanded(expanded) callback lets an editor react (the habits editor swaps its toggle's aria-label). Include from any page that renders elist rows; the guard makes repeat includes a no-op. {% endcomment %}
