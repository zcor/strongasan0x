# Handoffs

Use this directory only for concise, dated context that the next Strong as an 0x session would
otherwise have to reconstruct. A handoff is not a changelog and must not contain credentials,
attestation text, health data, or chat transcripts.

Create `YYYY-MM-DD-<specific-topic>-handoff.md` only for an unfinished diagnosis, unlanded
worktree, changed theory, pending deployment, or unresolved decision. Include status, what
changed, proven versus unconfirmed facts, the first next step, loose ends, and any agent-owned
worktree path, branch, tip, and release decision. Skip it for a fully closed trivial change.
