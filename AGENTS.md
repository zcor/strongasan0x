# Dashboard UX conventions

- Dashboard controls scroll with the page. Do not make them fixed or sticky.
- Keep one page-level scroll; do not create a separately scrollable habits section unless explicitly requested.

# Commit conventions

- Use Conventional Commit messages for every commit: start with a lowercase type and colon, such as `fix:`, `feat:`, `chore:`, `refactor:`, `test:`, or `docs:`.
- Before committing, verify the proposed message follows that format.
